# Roastmate

Playable static chess prototype with a local opponent, a strategy panel, and 1,010 move-specific joke templates.

## Upload to GitHub

Extract this ZIP. Upload all the extracted files together to the root of your repository. Do not upload the ZIP itself. index.html must appear directly in the repository file list.

## Deploy with Vercel

Import the GitHub repository. Select Other for the framework preset. Leave the build command empty. The site files are at the repository root, so use . (a single dot) as the output directory if Vercel asks for one. No dependency installation or server is required.

## Notes

The coach uses original scripted jokes, not a live AI service. Chess and move advice run in the browser. Joke history is saved separately in each browser. The chess.js third-party license is included in chess-LICENSE.txt.
